# .github

Organization-wide defaults for Smart-Treasury-Account-STA. GitHub reads two
files from this repository:

| File                | Where it shows up                                                                                              |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| `profile/README.md` | The organization's public profile page                                                                         |
| `SECURITY.md`       | The "Security" tab and "Report a vulnerability" link of every repository in the organization that has no `SECURITY.md` of its own |

Keep repository-specific documentation in the repositories themselves. This
repository only holds what applies to all of them.
